# 把话费交给 AI 查一遍

一段可以直接复制的提示词：把手机号交给能操作网页的 AI 助手，配合短信验证码登录，它会帮你查账单、退掉多扣的钱，再算算要不要换个更便宜的套餐。移动、联通、电信都能用。

## 怎么用

1. 打开 [PROMPT.md](./PROMPT.md)，复制分割线下面的整段。
2. 把【号码1】【号码2】换成你自己的号码（只有一个就删掉一个）。
3. 发给能用浏览器的 AI 助手，它要验证码时把短信验证码告诉它。
4. 换主套餐、投诉、销户这类事，它会先问你，你点头才办。

## 它会做什么

- 查最近 3～6 个月的实际用量和扣费
- 找出没用的会员、附加包，能免费退的就退
- 对比「旧套餐清理一下」和「换新套餐」哪个更省，多张卡一起算
- 家庭套餐 / 亲情号 / 宽带绑定时，先说清动一张会不会连累别的号
- 网上办不了就走客服，还不行告诉你怎么升级投诉
- 办完对照截图核对结果，不把「点了成功」当成「办好了」

## 注意

- 只用你本人名下的号码。
- 验证码只给正在帮你操作的 AI，不要发到别处。
- 有合约、宽带绑定、靓号低消的，降档可能要违约金，AI 会先查清楚再说。
- 保号和销户不是一回事：还想留号就优先保号。
- 各地套餐和规则不一样，以运营商官方页面和短信通知为准。
